04 — Match Timer optional

Set each half separately — they don't have to match (e.g. 25 for the 1st half and 25 for the 2nd, or any custom split your organization/league uses). Each half starts counting up and, by default, freezes ("pins") at the end of that half — e.g. it stops at the number you set and stays there, just minutes and seconds, no "+" added. Use the stopwatch button (⏱) on the widget any time to switch on the running "MM:SS+MM:SS" added-time clock, and press it again to switch it off and pin the display again. When you tap "Next half" (⇥), added time turns off automatically and the clock continues straight from the end of the 1st half instead of resetting to 0:00. The +1' button is separate — it only shows an announced "+3' added" badge on screen and never affects the running clock.

Either way, there's a show/hide button on the widget itself to toggle it live from vMix/OBS whenever you want.

06 — Size

Text is sized relative to the browser source's own resolution, not fixed pixels. Set the browser source's Width/Height to your target size, then fine-tune here — it stays sharp at any size.

07 — Controls

Adds +/− score buttons, resize buttons, a timer show/hide toggle, and (for football) stoppage-time / next-half buttons directly under the scoreboard — so you can run the whole match straight from vMix or OBS. Enable mouse clicks on the browser source/input and you're set.

Controlling the match live

OBS Studio

  1. Sources → + → Browser, paste the URL
  2. Right-click it → Interact
  3. Click any button to update live

vMix

  1. Add Input → Web Browser, paste the URL
  2. Right-click → enable mouse/keyboard input
  3. Click any button to update live

Score, timer, half, stoppage time, size, and show/hide state are all remembered by the browser the widget runs in — reloading that browser source resumes right where you left off.
