Controlling the match live

OBS Studio

  1. Sources → + → Browser, paste the URL
  2. Right-click it → Interact
  3. Click +/− to update the score live

vMix

  1. Add Input → Web Browser, paste the URL
  2. Right-click → enable mouse/keyboard input
  3. Click +/− to update the score live

The score and timer are remembered by the browser they're running in, so reloading that browser source resumes right where you left off — no need to reopen this builder mid-match.
